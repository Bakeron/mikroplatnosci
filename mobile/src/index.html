        Skopiuj kod, otwórz google.com/device, wklej go tam i zgódź się na dostęp:

        Aplikacja zobaczy tylko swój ukryty folder na Dysku, nie Twoje pliki. Po zgodzie wróć tutaj - połączy się sama.

        Synchronizacja potrzebuje identyfikatora Twojego projektu w Google Cloud (raz, za darmo):

        1. , zaloguj się i utwórz Nowy projekt o nazwie Mikroplatnosci.
        2. Menu ☰ → Interfejsy API i usługi → Biblioteka → Google Drive API → Włącz.
        3. Menu → Google Auth Platform → Rozpocznij: nazwa Mikropłatności, Twój e-mail, odbiorcy Zewnętrzni → Utwórz.
        4. Dostęp do danych → Dodaj lub usuń zakresy → ręcznie wpisz https://www.googleapis.com/auth/drive.appdata → Dodaj → Zapisz.
        5. Odbiorcy → Opublikuj aplikację (bez tego zgoda wygasa co 7 dni).
        6. Klienci → Utwórz klienta → typ Telewizory i urządzenia z ograniczonym wprowadzaniem danych → Utwórz. Skopiuj identyfikator i tajny klucz do pól wyżej.

        Przy logowaniu Google ostrzeże „nie zweryfikował tej aplikacji” - to normalne dla własnego projektu: Zaawansowane → Przejdź do Mikropłatności. Identyfikator zostaje tylko na tym urządzeniu. Wygodniej zrobić to na komputerze - ten sam identyfikator wpisuje się na PC i w telefonie.
